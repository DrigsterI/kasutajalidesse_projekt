Rühmatöö juhend
Ülesanne
Luua kahekesi veebileht kasutades HTML-i ja SASS-i.
Projekti eesmärk on näidata semantilise HTML-i kasutamist, SASS-i kasutamist, muganduvat disaini, vormide loomist ja Git-i kasutamist meeskonnatöös
Projektil võiks olla unikaalne huvitav idee, kuid võib saada ka kuskilt otsest inspiratsiooni.

1. Üldised nõuded
    ● Projekt peab olema Git repositooriumis
    ● Repositooriumist peab olema näha arendusprotsess
    ● Projekti ei tohi üles laadida valmis kujul ühe commit’iga
    ● Projekt tuleb edukalt kaitsta

2. Projekti sisu (veebileht)
    ● Vähemalt üks navigatsioon
    ● Sissejuhatav tekst
    ● Muganduv vaade (mobile/tablet/desktop)
    ● Vähemalt 2 lehte või navigeeritavat sektsiooni (ankurlingid)
    ● Vähemalt 2 vormi
    ● Pildid või meediaelemendid
    ● Favicon
    ● Logo

3. Nõuded koodile
    ● Semantiline HTML
    ● SASS muutujad
    ● Korduste vähendamine (nt mixin)
    ● Eeldefineeritud stiilid (font, värvid, suurused)
    ● Pseudoklassid (:hover jne)
    ● HTML5 vormielemendid

4. Repositooriumi nõuded
    ● README fail (idee, kirjeldus, makett)
    ● Nähtav arendusprotsess
    ● Nähtav tööjaotus

5. “Nice to have”
    ● JavaScript funktsionaalsus
    ● Animatsioonid
    ● Mitu laadilehte
    ● Mitu lehte sama stiiliga
    
6. Mida ei tohi kasutada
    ● React, Next.js, Svelte jne
    ● Bootstrap, Tailwind, Materialize
    ● SCSS või puhas CSS
    ● Valmis UI mallid
